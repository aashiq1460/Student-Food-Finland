# Student Food Finland

Student Food Finland is a web application for finding student restaurants in Finland and viewing their daily and weekly menus.

The project was created for the TX00EY23 Web Application Development course.

## Features

- Display student restaurants
- Search restaurants by name
- Filter restaurants by city
- Filter restaurants by service provider
- View daily menus
- View weekly menus
- Save favorite restaurants
- Show favorite restaurants only
- Display restaurant location on a map
- Find and highlight the nearest restaurant
- Responsive design for mobile devices

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- REST API
- LocalStorage
- Geolocation API
- OpenStreetMap

## API

Restaurant information and menus are loaded from the Metropolia restaurant REST API.
